Kaggle NLP demo

Disaster tweet classification, from notebook to Render runtime.

A compact end-to-end project for classifying emergency-related tweets with a BiLSTM model, ONNX runtime inference, FastAPI serving, Jinja UI, and SQLite prediction logging.

Open App Training Notes Deployment Notes
Project review ONNX-first inference path, PyTorch fallback design, and a lightweight runtime container for Render free-tier demos.

The model artifacts are bundled with the image for a simple demo deployment; SQLite is used as temporary prediction logging storage.

Threshold 0.5200

Model

Bidirectional LSTM classifier with 100-dimensional embeddings, two LSTM layers, hidden size 64, dropout 0.28, and a sigmoid binary output.

Runtime

The service tries ONNX Runtime first for a small Render image, while the full local image keeps PyTorch support for development and fallback.

Logs

Predictions are written to SQLite with probability, label, threshold, backend, warnings, and the final normalized text.
